# Credits

ekram.md is built on open source.

## The editor

- **[ProseMirror](https://prosemirror.net/)** — the document model and editing
  engine underneath everything
- **[Milkdown](https://milkdown.dev/)** — the markdown editor built on it, and
  the Crepe configuration this application starts from
- **[remark](https://remark.js.org/)** and the unified ecosystem — parsing and
  serializing markdown
- **[CodeMirror](https://codemirror.net/)** — source mode and code blocks

## Rendering

- **[KaTeX](https://katex.org/)** — mathematics
- **[Mermaid](https://mermaid.js.org/)** — diagrams
- **[DOMPurify](https://github.com/cure53/DOMPurify)** — sanitizing exported HTML

## The application

- **[Electron](https://www.electronjs.org/)** — the desktop runtime
- **[Vue](https://vuejs.org/)** — the interface
- **[Vite](https://vite.dev/)** and **[electron-vite](https://electron-vite.org/)** — the build
- **[chokidar](https://github.com/paulmillr/chokidar)** — watching files for
  external changes

## Testing

- **[Vitest](https://vitest.dev/)** and **[Playwright](https://playwright.dev/)**

Each of these is used under its own licence. Thank you to everyone who wrote
them.
