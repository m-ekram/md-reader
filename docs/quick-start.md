# Quick Start

ekram.md edits markdown as formatted text. There is no split pane and no preview
to keep in sync: what you type becomes what it means, in place.

## The basics

Type `# ` at the start of a line for a heading, `- ` for a bullet, `> ` for a
quote, and ``` ``` ``` for a code block. The marker disappears and the block
takes its shape. `**bold**` and `_italic_` work as you type them.

Press `Ctrl+/` at any time to see the raw markdown for the whole document, and
again to come back. Nothing is converted when you switch: both views edit the
same text.

## Files

| Action | Shortcut |
| --- | --- |
| New document | `Ctrl+N` |
| Open a file | `Ctrl+O` |
| Save | `Ctrl+S` |
| Find and replace | `Ctrl+F` |
| Run any command | `Ctrl+Shift+P` |

Files are only written when you save. Opening a document and closing it again
never changes it, even if the editor would have written it back slightly
differently.

## Working in a folder

`File ▸ Open Folder…` puts your notes in the sidebar. From there:

- **Outline** (`Ctrl+Shift+1`) lists the headings of the current document
- **Articles** (`Ctrl+Shift+2`) lists every markdown file in the folder
- **File Tree** (`Ctrl+Shift+3`) shows the folder as it is on disk
- **Search** (`Ctrl+Shift+F`) searches the text of every file

`Ctrl+P` jumps to a file by name without leaving the keyboard.

## When you want fewer distractions

**Focus Mode** (`F8`) dims everything except the paragraph you are in.
**Typewriter Mode** (`F9`) keeps that paragraph near the middle of the window.
They work together.
